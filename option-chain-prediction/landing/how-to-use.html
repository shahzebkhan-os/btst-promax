How to Use

Clear steps to run the pipeline and see results.

1) Run the ML pipeline

cd option-chain-prediction
python3 scripts/generate_sample_data.py
python3 -m src.train --data data/sample_train.csv --out models.pkl --horizon 1
python3 scripts/build_sentiment.py
python3 -m src.predict --data data/sample_train.csv --model models.pkl
python3 scripts/publish_web_data.py

2) Start the web server

cd option-chain-prediction/landing
python3 -m http.server 8081

3) Open the dashboard

Go to http://localhost:8081/analysis.html and refresh after each run to see new predictions.
